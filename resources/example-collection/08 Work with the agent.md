# Work with the agent

The agent reads this folder and changes text when you ask. What it changes in your words arrives as suggestions for you to accept or reject. This file is a rough draft of the last part of the walk, with slips left in on purpose. The agent needs an account: sign in from Settings before you start. Where a command has no key, its name is in bold: press <kbd>⇧⌘P</kbd>, type the name and press <kbd>↵</kbd>.

> **Skills.** A skill is a set of instructions the agent follows, kept as a file. <kbd>⌥⌘1</kbd> runs Copy-edit on this file, <kbd>⌥⌘2</kbd> runs Review and <kbd>⌥⌘3</kbd> runs Clean-up. Run Copy-edit now: the slips in the two paragraphs below come back as suggestions, each one to accept or reject. <kbd>⇧⌥⌘1</kbd> opens the first skill as a conversation. **Help with this report** is the fourth skill. It works on a whole folder, not on one file, and it is also in the menu of a folder's row in the Files pane, under <kbd>⌘K</kbd>. **Manage skills…** lists the skills and is where you add your own.

## Coming down

The path drops threw a hanging wood, and the the village roofs come back one at a time. First the church, then the mill, then the long barn which they have made into three houses.

Its always later than I think. The light goes early under the trees and i have twice come down the last field in the dark, feeling for the gate.

> **Conversations.** Press <kbd>⌘J</kbd> to open the Agent in the right-hand pane and type a request, for example: make the second paragraph under Coming down one sentence shorter. The answer comes as a suggestion in the text. **Start a new conversation** begins a fresh one, <kbd>⌃⌘T</kbd> shows the conversations you have open, and **Close the current conversation** closes the one in front. **Ask the agent about this…** is in <kbd>⌘K</kbd> in a paragraph, with words selected, on a heading (it quotes the whole section) and at a table or code block: it opens the Agent with that text quoted in the message box and sends nothing, so type your question after it and press <kbd>↵</kbd> when it reads right. A long section is cut at a block boundary and says so.

> **Models and accounts.** **Manage assistant accounts** shows which accounts you are signed in to. **Switch the model for this chat** and **Set the reasoning level for this chat** change how the agent works in the conversation in front, and **Refresh models** fetches the current list of models.

## What the long way teaches

It takes twice as long, and I remember four times as much of it. By the road I would be home in an hour and could not tell you one thing I had passed.

> **Scratchpad.** <kbd>⇧⌘J</kbd> opens the Scratchpad in the right-hand pane. It holds scraps: sentences you have cut and may want back. Select the last sentence above and press <kbd>⌘⇧X</kbd> to cut it to a scrap.
