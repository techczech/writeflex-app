# Start here

This folder is the Example collection. It is a folder of its own, pinned on the start screen, and holds twelve plain Markdown files. Ten of the others each teach the commands for one task, on text you can change freely; [[11 Objects]] holds a working sample of every object you can insert, with how to edit, add and remove each.

> **Try it.** Put the caret on **02 Shape the document** in the list below and press <kbd>⌥↵</kbd> to follow the link.

## The ten chapters

- [[01 Write]]: format text, edit lines, insert objects, tables, lists and checkboxes
- [[02 Shape the document]]: fold, move blocks and sections, headings and levels, jump between headings
- [[03 Stay focused]]: typewriter and distraction-free, writing sessions and goals, focus modes
- [[04 Listen]]: read aloud
- [[05 Review and versions]]: versions and compare, review changes, review sessions
- [[06 Find and manage files]]: files and quick open, tabs, search, links and wikilinks
- [[07 Collect and plan]]: Reading Room; collections, Board and Folio outline; capture ideas; sources
- [[08 Work with the agent]]: Scratchpad, conversations, skills
- [[09 Share and export]]: copy as, export and presets
- [[10 Set up WriteFlex]]: view and text size, action bar, themes and sounds, settings and shortcuts

## How a chapter works

Each chapter has a few blocks like the one above. A block says what to press and where; the text to try it on is directly beneath it. Nothing here can be broken: <kbd>⌘Z</kbd> undoes, and every file keeps its history.

> **Try it.** Press <kbd>⌘K</kbd> anywhere to see what you can do where the caret is, and <kbd>⌘/</kbd> for every key.

## When you have finished

**Remove the example…** on the start screen moves this folder to the Bin and nothing else. Your own folders are never touched.
