# Find and manage files

The piece about the walk is spread over the files of this folder. This file is the list of what is where. Many of the commands here act on the Files pane or the tabs, not on this text, so each instruction says where to be. Where a command has no key, its name is in bold: press <kbd>⇧⌘P</kbd>, type the name and press <kbd>↵</kbd>.

> **Tabs.** Open two of the files listed under **What is where**, so that three tabs are open. <kbd>⇧⌘]</kbd> goes to the next tab and <kbd>⇧⌘[</kbd> to the previous one. <kbd>⌘2</kbd> lists the open tabs. <kbd>⌥⌘P</kbd> pins this tab to the tab strip, and unpins it again. <kbd>⌃⌘⇥</kbd> and <kbd>⌃⇧⌘⇥</kbd> go to the next and the previous tab of the right-hand pane.

> **Files and quick open.** <kbd>⇧⌘K</kbd> opens Quick Open: type a few letters of a file's name, in any order, and press <kbd>↵</kbd>. <kbd>⌥⌘]</kbd> and <kbd>⌥⌘[</kbd> open the next and the previous file in the folder. <kbd>⇧⌘E</kbd> opens the Files pane on the left, and **Filter files…** narrows its list as you type. **Clear document…** empties the file you have open, after asking. **Pin this workspace** keeps this folder on the start screen, and **Unpin this workspace** takes it off.

> **A file's row.** These work in the Files pane, with a file's row selected. <kbd>↵</kbd> opens the file, <kbd>F2</kbd> renames it, <kbd>M</kbd> moves it to another folder, <kbd>⌘D</kbd> makes a copy and <kbd>⌘⌫</kbd> moves it to the Bin. <kbd>⌘K</kbd> on the row lists these with **Pin favourite**, which keeps the file under Favourites in the pane, **Reveal in Finder** and **Copy file path**. Try them on the copy you made, not on a lesson.

> **A folder's row.** These work in the Files pane, with a folder's row selected. <kbd>⌘N</kbd> makes a new file in the folder and <kbd>F2</kbd> renames the folder. <kbd>⌘K</kbd> on the row offers **New subfolder…**, **Reveal in Finder** and **Delete folder…**. **Focus on this folder** shows only that folder in the pane, and **Clear focus** shows everything again. From a file, **Focus on the open file’s Collection** does the same for the folder the file is in, and **Clear folder focus** undoes it. Choose **New subfolder…** on the Example collection's row first, so that there is a folder to try these on.

> **Links and wikilinks.** Type <kbd>[[</kbd> at the end of the line under **To link** and pick a file from the list: that inserts a link to it. Put the caret on a link under **What is where** and press <kbd>⌥↵</kbd> to follow it. <kbd>⌃⌘←</kbd> goes back along the links you have followed and <kbd>⌃⌘→</kbd> goes forward. The last link in that list points to a file that does not exist yet: with the caret on it, <kbd>⌘↵</kbd> makes the file.
