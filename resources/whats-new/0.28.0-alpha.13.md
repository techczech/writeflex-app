# WriteFlex 0.28.0-alpha.13

## Versions for your OneDrive folders

WriteFlex keeps your saved text on this Mac before confirming a save, then copies versions into the Collection as OneDrive allows. Text waiting to reach that store appears in Versions as “kept on this Mac”. You can read, compare and restore it without an agent. This also works when automatic snapshots are set to Manual.

## Reconcile copies without locking your work

WriteFlex recognises sync copies using recorded computer names and their contents. It keeps both texts before reconciling them. Identical or superseded copies are moved into a recoverable folder inside the Collection. A proven newer version can replace its ancestor, and non-overlapping edits with a shared version can be combined.

When edits overlap or the evidence is insufficient, both files stay and their texts remain available in Versions and Compare. Your folder opens and saves independently on each Mac; there is no Collection lock.

This alpha covers Markdown documents up to 32 MB. Unknown copy names are left alone.

## Compare two Folio versions

In the Versions tab, choose Compare with working draft, or pick any two versions. Each part shows as unchanged, changed (words added and removed), only in one version, or moved; open a changed part to see both texts with the differences marked. Inserted tables and images show which version each side used.

## Other fixes

The Shelf collection picker appears when the Reading Room first opens. Undo and Redo after an accepted Scratchpad Put back carry its text and placement through ordinary editor history, so Redo no longer causes a save conflict or prevents normal closing.

Command-W now closes the tab even when a widget has the keyboard, and a widget you have clicked into can no longer swallow Command-Q.
