# WriteFlex 0.28.0-alpha.10

## Open your synced folders on either Mac

WriteFlex no longer locks a whole folder because it is open on another computer. You can open and save your local OneDrive copy without waiting for another Mac to close its window or for a lock to sync.

The command line sends requests to WriteFlex on this computer. Another Mac with the same synced folder open leaves those requests alone. Checks for changed document text, saved history and local undo remain in place.

Automatic reconciliation of sync-created duplicates and versions independent of the agent are still to come. This update removes the folder lock; it does not yet add those facilities.
