# WriteFlex 0.28.0-alpha.11

## Save a version of a whole Folio

Inside a Folio, Shift-Command-S now asks "Whole Folio or this part only?". Whole Folio saves every part in running order, the Index Note, the files not in the outline (you can leave them out), and the tables, images and widgets the text inserts. Research, offcuts and the archive are not copied. File > Save Folio Version… goes straight to the whole Folio.

Your own waiting changes are gathered into the text before saving; an agent's suggestions stay in the margin and are left out. If the Folio changes while the window is open, nothing is saved and the window shows what changed.

## See a Folio's versions

The new Versions tab (Option-8, or View > Open Folio Versions) lists a Folio's saved versions, newest first, and shows what each one holds. Opening a version read-only, comparing and restoring come in later updates.

## Backup carries inserted files

When Git backup is on, each Folio version takes frozen copies of its inserted tables, images and widgets with it. Your working data and research folders still stay out.
