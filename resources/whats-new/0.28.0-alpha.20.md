# WriteFlex 0.28.0-alpha.20

## Personal links

Each shared link now has a **People** section. Add someone by name and email, and they get their own link to the same piece. Their comments carry their name on any device, and other readers never see their email. You can see whether each person has opened their link and how many comments they left, switch one person off, or give them a new link if theirs has been passed on.

**Email invitation** opens a ready-written draft in Mail with the person's link. You edit it and press Send; WriteFlex sends nothing itself.

**Anyone with the link** stays on unless you turn it off. Off means only personal links work.

To use People, open **Settings › Sharing** and press **Update sharing service** once.
