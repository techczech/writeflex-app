# WriteFlex 0.29.0-alpha.7

- A crash when switching tabs while WriteFlex was busy is fixed.
- Panels keep your place and your typing when a refresh fails, and offer Retry.
- The keyboard lands where you expect after jumps, moves and searches.

## Crash fixed

WriteFlex could stop with an endless-update error when you switched tabs while it was busy. It showed up most often when opening a part from a Folio's cards.

## When a refresh fails

The Versions panel, the Board and the Folio Versions timeline keep your place, your selection and anything you were typing, and offer Retry.

## Smaller fixes

- Restore and Copy of an older file version act on exactly the version you saw when you opened the sheet.
- Search and Outline jumps land in the document once it is on screen, and close a Collection that was covering it.
- The Files list puts the keyboard on the file you asked for once it appears. A moved or added Folio card gets the keyboard back.
- The command palette keeps its highlight on the same item as results reorder, and a Zotero panel no longer takes the keyboard away from it.
- A slow check of shared links no longer overwrites a change you just made.

## Vault sync stays off

Sending a vault's changes through Git between Macs is in this version but switched off by default, as before. Leave the switch in Settings › Advanced off unless you are testing.
