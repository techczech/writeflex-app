# WriteFlex 0.29.0-alpha.2

- Restoring a checkpoint no longer deletes writing you added after it.
- Settings now live in one window you can search. Open it with ⌘,.
- The command palette lists commands by task, and includes file actions for the open document.
- New pieces in a Collection take their file name from their title.
- Review changes made outside WriteFlex in groups instead of one at a time.
- Writing modes are calmer, with new typewriter sounds and a readable dark-theme selection.

## Safer restores

Restoring a checkpoint used to delete a file if it had been created after the checkpoint, even when you had written in it since. WriteFlex now checks first: if a restore would remove writing it has no record of, it stops before changing anything and tells you. A related fix applies when accepting an assistant's proposal fails part-way: WriteFlex removes a file it made only if the file still holds exactly what WriteFlex wrote.

## Settings

Press ⌘, to open Settings. Search for any preference, change keyboard shortcuts, and reset a single setting to its default. The menu bar shows the shortcuts you choose. Your earlier settings are carried over.

## The command palette

Press ⇧⌘P to see commands grouped by task, each group with an icon. Press Right to open a group, Left to go back, and Esc to close. Type to search as before. Actions for the open document are there too: Reveal in Finder, Copy Path, Open With, Rename, Move, Duplicate, Export and Move to Bin.

## Names for new pieces

When you start a new piece in a Collection, WriteFlex renames the file once from its title, following the pattern of the files beside it. It waits until you have left the title line, switched tabs or stopped typing for ten seconds. The notice has an Undo button.

## Changes made outside WriteFlex

When other programs change your documents, the status bar says how many documents have changes to review. The review now groups them by source, kind and folder, shows a preview, and lets you accept or reject a whole group. Changes to documents that no longer exist can be cleared with one click.

## Writing modes

Distraction-free mode hides the metadata bar. Typewriter mode keeps your line in place on short and empty documents, and its adjuster fades after 30 seconds. In the dark theme the editor background matches the sidebar and selected text stays readable. There are three sets of typewriter sounds; Crisp is the default. Status-bar popovers stay on screen and open one at a time.

## Links after renames and moves

Links survive more renames and moves. A moved document keeps its own links to pictures and other documents, files moved together keep their links to each other, and image links pasted into documents inside folders keep working when the document moves. A rename that happens while a save is in progress no longer overwrites the newer text.

## No more developer-tools dialog

On a Mac without Apple's developer tools, saving a version could open a dialog asking you to install them. WriteFlex no longer triggers it.
