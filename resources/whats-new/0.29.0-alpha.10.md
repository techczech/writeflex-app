# WriteFlex 0.29.0-alpha.10

- Adding tags in a Collection keeps newer text another program saved.
- Switching a Folder Piece between one document and many keeps newer text too.
- WriteFlex no longer crashes when it cannot store your list of tabs.

## Your newer text is kept

Two actions could overwrite text that another program had saved to the same file a moment earlier. Adding tags to a document in a Collection, and switching a Folder Piece between one document and many, now keep that newer text.

## No crash over the tab list

If WriteFlex cannot store the list of open tabs, it carries on and the editor stays usable.

## Things land where you are

A command that finishes late no longer acts on a place you have already left. This covers opening from the Board, opening a Scratchpad version, opening a folder, and Folio citation and flag actions. Open tabs follow files that are moved or renamed in a Collection.

## Smaller changes

- The Folio Outline keeps its rows and the keyboard when a read fails, and changes to the running order match the Outline you see.
- Folio comparisons stay open when a refresh fails.
- Collection filter commands and Open Outline put the keyboard where they say.
- A Folio chapter that is still loading no longer pulls the cursor away.

## Vault sync stays off

Sending a vault's changes through Git between Macs is in this version but switched off by default, as before. Leave the switch in Settings › Advanced off unless you are testing.
