# WriteFlex 0.28.0-alpha.14

## Take one part from an old Folio version

When you compare a saved version with your working draft, a changed part offers Take that text. The old text waits in the margin as a suggestion; accept it like any other, and your current text is kept as a version first. Take that text, keep mine in Scratchpad also puts your current text in the Scratchpad.

## Export a version and mark it as sent

Export this version (Versions tab, File menu or palette) makes a Word or HTML file from that version's saved text, in that version's order. Tick Mark as sent to and type a name, and the Versions tab shows who got which version.

## Send text from old versions to the Scratchpad

In an old version or a comparison, select text or use the icon beside a paragraph and choose Send a copy. The Scratchpad card names the version, part and writer, and Open in that version takes you back there.
