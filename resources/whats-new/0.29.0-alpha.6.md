# WriteFlex 0.29.0-alpha.6

- Restoring an older version and files that OneDrive is still downloading are handled more safely.
- Collections open much faster in large vaults.
- Many small fixes to export, the Board, suggested edits, versions, Folios and ReadFlex drags.

## Your text is safer

Before restoring an older version, WriteFlex checks that a readable copy of your current text is kept, in ordinary and OneDrive folders, and refuses if it cannot. If a file is briefly unreadable, because OneDrive is downloading it or it is locked, its tab and draft stay open with Retry instead of looking deleted. Closing the tab of a deleted file throws away only the text you confirmed.

## Collections

Opening a Collection is much faster in large vaults, and switching documents is a little faster. If the file list or Settings cannot load, they offer Try again instead of looking empty.

## Smaller fixes

- Word and HTML export open for what you asked to export.
- The Board stays on the Collection you are in, and Tab stays inside the command palette.
- Decline all declines only the edits it asked about. Name Version saves for the part or Folio it was opened on. Compare shows only the current comparison.
- Open a Folio ignores out-of-date lookups, and the Folio workspace offers Open or Start outline correctly.
- A ReadFlex Area can be dragged into a draft straight after you draw it. A refused drop leaves no stray image or quote.
- Backup status no longer flickers to "connecting" while it retries.

## Vault sync stays off

Sending a vault's changes through Git between Macs is in this version but switched off by default, as before. Leave the switch in Settings › Advanced off unless you are testing.
