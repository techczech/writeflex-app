# WriteFlex 0.29.0-alpha.1

- Update WriteFlex in place on a Mac: press Update and it downloads, checks and restarts into the new version.
- Get early versions: switch on alphas in Settings › About to try new features first.
- The menu bar now lists WriteFlex's commands, grouped by task.

## Updating in place

When a new version is out, the status bar says so. Nothing is downloaded until you press **Update**. WriteFlex then downloads the new version, checks that it is the one published and signed by its developer, and restarts into it. If a restart now would interrupt something (unsaved changes, the assistant still working, an export, a shared link being published or a backup running), it waits and shows **Restart** when you are ready. Your documents and settings stay as they are. Windows copies still link to the download page.

## Early versions

Switch on **Get early versions (alpha)** in Settings › About to be offered alphas as well as releases. Alphas come first and can break. Switch it off again and you stay on your alpha until the next release, which then updates as usual.

## The menu bar

The menu bar is built from the same list of commands as the command palette, grouped by task, so features are easier to find from the menus.
