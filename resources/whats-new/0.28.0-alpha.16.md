# WriteFlex 0.28.0-alpha.16

## Three texts where you both changed a part

In the Decide step of a Word revision, a part that both you and the reviewer changed since you sent it now offers Read the three texts. Each changed paragraph shows what you sent, what they wrote and your text now, side by side. Choose Use theirs, Keep mine or Edit by hand for each one. A paragraph only you changed keeps your text; a change only they made still waits for you to accept or decline it.

## Versions of tables, images and widget pages

Select an inserted file (a CSV table, an image or an HTML widget) in the Folio's Inspector to see its versions and which Folio versions used each one. Save version, compare an old version with the working copy, restore one, or save it as a separate copy. Restoring keeps your current copy as a version first and never deletes anything. Files over 25 MB are listed but get no versions.

Agents can save and compare these versions, but only you restore them.
