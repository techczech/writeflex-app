# What’s new in WriteFlex 0.28.0-alpha.9

- The Rail shows a diary glance: today’s word count, the day number and the last fourteen days as dots.
- Saved diary queries read your designated Diary from any Workspace, with project, date and word-range filters and daily or weekly totals.
- Check for Updates in the app menu, the command palette and Settings tells you whether a newer version is available. It never downloads or installs anything.
- History is now kept forever by default, so clean-up no longer removes snapshots that named versions depend on.
- Diary activity is saved when you close WriteFlex, and day totals are rebuilt from the surviving records if the recorded totals are damaged.
