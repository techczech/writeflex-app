# WriteFlex 0.29.0-alpha.4

- Two new typewriter sounds: Olivetti Lettera 22 and Hermes Baby (Settings › Sounds).
- Renaming or moving a document in a large vault reads fewer files at once.

## Typewriter sounds

Settings › Sounds › Typewriter now offers five sounds in a dropdown. The two new ones are recordings of an Olivetti Lettera 22 and a Hermes Baby, with a bell and the carriage return on Return. Crisp is still the default, and a sound you already chose stays chosen.

## Vault sync stays off

Sending a vault's changes through Git between Macs is in this version but switched off by default, as in alpha.3. Leave the switch in Settings › Advanced off unless you are testing.
