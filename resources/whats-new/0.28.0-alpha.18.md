# WriteFlex 0.28.0-alpha.18

## Sidebars you can drag

Dragging a sidebar wider now follows the pointer and stops where the editor would have less than 55% of the window. The left sidebar no longer snaps back to its narrowest width, and the right sidebar no longer closes when you drag it too far. Widening the right sidebar first narrows the left one. When the right sidebar opens, the left one narrows only as far as the editor needs, and widens again to your width when there is room.

## Security update

WriteFlex now runs on Electron 43.8.6, which includes the latest security fixes from Chromium and V8.
