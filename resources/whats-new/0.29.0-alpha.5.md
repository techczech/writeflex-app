# WriteFlex 0.29.0-alpha.5

- Files and search are faster in large vaults, and search never shows text a file no longer has.
- Folio Comments and Open a Folio cope better while loading and when something goes wrong.
- Restoring an older version tells you if its history entry could not be saved.

## Restoring an older version

If the file comes back but WriteFlex cannot record the restore in its history, it now says so and names the safety copy it kept, instead of staying silent.

## Folios

The Comments tab always shows the Folio you are in. If it cannot read the comments it offers Try again, and when there are none it says "Nothing is waiting". Open a Folio lets you start typing while the list loads, and offers Try again if loading fails.

## Shared pages

Before a reader presses Send on a proposed edit, the page shows who will see it and the name it goes under. A private draft stays private.

## Board

After you make an idea from an offcut, the next keyboard shortcut goes to the Board.

## Vault sync stays off

Sending a vault's changes through Git between Macs is in this version but switched off by default, as before. Leave the switch in Settings › Advanced off unless you are testing.
