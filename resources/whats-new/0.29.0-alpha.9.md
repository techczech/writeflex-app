# WriteFlex 0.29.0-alpha.9

- Renaming a part of a Folio keeps it selected, with the keyboard still on it.
- Enter in Search opens only a result of the search you can see.
- Files offers Try again when it cannot read your workspace.

## Folios keep your place

When you rename a part of a Folio, or fix its title from the Folio, its card stays selected and the keyboard stays on it. ⌘Z undoes the last title fix or move. The view you open or switch to takes the keyboard, and the toolbar no longer spills over the sidebar.

## Search and Files

Enter in Search opens a result of the search on screen. Before, a result from the previous search could open while the new one was still arriving. If WriteFlex cannot read your workspace, Files says so and offers Try again; if a later reread fails, the list you had stays.

## Versions and restore

Save version, Compare, Restore and Save as a copy now sit right under the working copy, so they stay in view. The copy WriteFlex keeps before a restore is labelled "Before a restore attempt", which stays true if the restore is refused. If a OneDrive version cannot be read, WriteFlex tells you to download it first.

## Smaller changes

- ⌘S confirms "Saved to disk · checkpoint kept in history".
- The command palette says why a greyed-out command is not available.
- Settings works from the keyboard, and the Git sync and Backup pages say which is which.
- Empty Board panels fold away, and each stage keeps a usable width.
- Images you drop into an Area and then abandon are cleared later, only when nothing refers to them.
- The review panel no longer redraws while no edits are waiting.

## Vault sync stays off

Sending a vault's changes through Git between Macs is in this version but switched off by default, as before. Leave the switch in Settings › Advanced off unless you are testing.
