# WriteFlex 0.29.0-alpha.8

- Fixed: text you typed while a document was saving could be lost after switching away and back.
- "Keep mine" and "Retry" on the changed-on-disk notice are readable again.
- Renaming and moving files in Files is safer and keeps the keyboard where it was.

## Your typing is safe while a document saves

In alphas 6 and 7, if you switched away from a document and back while it was still saving, WriteFlex could show a "Changed on disk" notice that was not true. Pressing Reload then threw away what you had typed during the save. More rarely, the document quietly showed older text. WriteFlex no longer mistakes its own save for a change made by another app.

## Smaller fixes

- "Keep mine" and "Retry" on the changed-on-disk notice are readable again.
- After you rename or move a file in Files, the keyboard stays on that file instead of typing into the document.
- A name that clashes with another file says so.
- Names that OneDrive and Windows cannot store are refused with a reason: names containing : * ? " < > |, or ending in a space or a full stop.
- Escape in Folio Compare closes only the comparison.
- A Collection keeps its list when a refresh fails, and offers Try again. Its filter menus close properly, and Escape in its search box clears the text.
- Importing settings no longer switches on experimental Git sync.

## Vault sync stays off

Sending a vault's changes through Git between Macs is in this version but switched off by default, as before. Leave the switch in Settings › Advanced off unless you are testing.
